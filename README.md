# Система учета жалоб пользователей

## Назначение

«Система учета жалоб пользователей» предназначена для регистрации и первичной обработки жалоб пользователей на различные объекты.

Программа позволяет создать жалобу, указать пользователя и объект жалобы, ввести описание проблемы и определить текущий статус обращения.

## Целевая аудитория

Целевой аудиторией системы являются:

* пользователи, которые хотят сообщить о проблеме;
* сотрудники службы поддержки;
* администраторы системы;
* сотрудники, ответственные за обработку жалоб.

## Предметная область

Предметная область проекта связана с регистрацией, хранением и обработкой обращений пользователей.

Пользователь может создать жалобу на определенный объект. Каждая жалоба содержит описание проблемы и текущий статус обработки.

Основные сущности предметной области:

* пользователь;
* жалоба;
* объект;
* статус.

На начальном этапе реализуется консольный сценарий создания и проверки жалобы. В дальнейшем система будет расширена до полноценного веб-приложения.

## Основные сущности

### Пользователь

Пользователь — человек, который отправляет жалобу.

Основные данные:

* имя пользователя.

### Жалоба

Жалоба — обращение пользователя с описанием обнаруженной проблемы.

Основные данные:

* пользователь;
* объект;
* описание;
* статус;
* дата создания.

### Объект

Объект — элемент системы, на который пользователь отправляет жалобу.

Например:

* товар;
* услуга;
* организация;
* публикация;
* технический сервис.

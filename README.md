# Система учета жалоб пользователей

## Назначение

Консольное приложение для регистрации, поиска и обработки жалоб пользователей.
На этапе ПР2 программа работает с коллекциями данных и сохраняет информацию
в JSON-файлах.

## Предметная область

Пользователь создает жалобу на определенный объект системы. Жалоба содержит
описание проблемы, дату создания и текущий статус.

Основные сущности:

- пользователь;
- жалоба;
- объект;
- статус.

## Функции проекта

- добавление пользователей;
- поиск пользователей;
- добавление объектов;
- поиск объектов;
- создание жалоб;
- поиск жалоб по описанию;
- поиск жалоб пользователя;
- поиск жалоб по статусу;
- изменение статуса жалобы;
- сортировка жалоб;
- вывод списка жалоб;
- получение статистики по статусам.

## Структура проекта

- `main.py` — главное меню и пользовательские сценарии;
- `users.py` — функции работы с пользователями;
- `objects.py` — функции работы с объектами;
- `complaints.py` — функции работы с жалобами;
- `statuses.py` — список допустимых статусов;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — безопасный ввод данных;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных

Данные хранятся в файлах:

- `data/users.json`;
- `data/objects.json`;
- `data/complaints.json`.

Для связи жалобы с пользователем и объектом используются их идентификаторы.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest -v
```

## Проверка качества кода

```bash
flake8 .
```

## План развития

В ПР3 планируется перейти от словарей и функций к классам и объектам
предметной области с сохранением JSON-хранилища и существующей функциональности.
В дальнейшем проект будет расширен с использованием Django, базы данных,
авторизации пользователей, REST API и Docker.
